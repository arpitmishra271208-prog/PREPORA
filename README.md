# PREPORA MVP

PREPORA is a preparation-intelligence product in the ALPHA ecosystem.

## Run
1. Open this folder in VS Code.
2. Open Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown by Vite.

## Branding
The supplied PREPORA brand-board assets are already integrated in `public/assets`. No third-party builder branding or watermark is included.

## Data
`src/data.ts` contains 120 process records across 12 categories. The records are intentionally marked `demo-unverified`; verify each process against its official authority before production use. The UI is data-driven, so adding a process does not require a new page.


Brand assets: PREPORA assets are in `public/assets/`. The ALPHA parent-brand wordmark is integrated into the “A product by” footer attribution via `alpha-primary.png`.
